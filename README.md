# Lenana School Media Tech - Media Core Hub

A full-stack class website for Lenana School Media Tech students.
Runs locally with NO database setup required!

## 🚀 Quick Start

### 1. Install Node.js
- Go to https://nodejs.org
- Download and install the LTS version
- Restart your computer

### 2. Install Dependencies
```bash
npm install
```

### 3. Run the Server
```bash
node server.js
```

### 4. Open Browser
Go to http://localhost:3000

## 🎓 Features
- Student/Admin authentication
- Instagram-like posts with media
- Comments system
- Admin approval panel (kasuku handles requests)
- Assignment management (admin only)
- Project collaboration
- Leaderboard with points
- Custom profile pictures
- Responsive liquid glass UI

## 📁 Project Structure
- `server.js` - Main server (uses local JSON file, no MongoDB!)
- `localdb.js` - Local JSON database
- `public/` - Frontend files
- `.env` - Configuration

## 💾 Database
This project uses a local JSON file (`localdb.json`) for storage.
No MongoDB Atlas or internet connection required!
